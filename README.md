# 🚀 Smart File Organizer (Python)

## 📌 Project Description

This is a Python automation project that organizes files into folders automatically based on file type.

## ⚡ Features

* Automatically sorts files into folders (Documents, Images, etc.)
* Saves time and keeps your system clean
* Beginner-friendly Python project

## 🛠️ Technologies Used

* Python
* os module
* shutil module

## 📂 How It Works

1. Scan folder
2. Identify file types
3. Move files into correct folders

## ▶️ How to Run

```bash
python organizer.py
```

## 🎯 Future Improvements

* Add GUI (interface)
* Auto-run in background
* Support more file types
